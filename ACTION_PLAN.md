# Fast Income Action Plan

## 1. Find a paid target

- Monitor bounty boards and issue trackers for labeled, scoped tasks.
- Prefer fixes with clear acceptance criteria and a 1-3 hour estimate.
- Reuse this utility as proof for automation, cleanup, reporting, and maintenance work.

## 2. Sell a small deliverable

- Send a one-sentence scope: problem, solution, and expected result.
- Quote a fixed price and a short deadline.
- Include 2-3 acceptance checks and one revision round.
- Do not start work until scope and payment method are agreed.

## 3. Deliver cleanly

- Make a focused change and add or update tests.
- Run the smallest relevant test suite, then record the command and result.
- Include a short summary, exact files changed, and instructions to run or preview.
- Do not include secrets or wallet private keys.

## 4. Fast payout channels

- GitHub bounties and issue trackers
- Small freelance platforms
- Direct work for local businesses: reports, exports, backup checks, and file cleanup
- Script customization gigs based on a tested base module
